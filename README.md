# MJ Psychológia

Jednoduchá statická webová stránka pre ambulanciu klinickej psychológie Marty Jonášovej.

## Lokálne spustenie

V tomto priečinku spustite ľubovoľný statický server, napríklad:

```powershell
python -m http.server 4173
```

Potom otvorte [http://localhost:4173/](http://localhost:4173/).

Stránka nevyžaduje build nástroj ani inštaláciu balíčkov. Logotypy z dodaných PDF sú uložené ako webové PNG assets v priečinku `assets/`.
